## 视觉验收基线与偏差

- 实现截图须使用“视口与状态矩阵”中相同的固定视口、状态、测试数据/权限和资产版本，保存于 `verification/`。
- 未经 UI 确认的视觉、交互或资产差异默认是缺陷，不得以“实现优化”名义跳过。
- P0：阻断任务、核心层级、关键操作、可访问性或品牌/合规资产错误，必须修复。
- P1：布局、层级、状态、关键尺寸、图标或背景图不一致，必须修复。
- P2：低影响细节，须记录影响、标记 `accepted` 并由具名 UI 确认人确认后才可通过。
