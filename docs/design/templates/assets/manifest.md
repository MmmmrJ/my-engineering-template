## 冻结与来源说明

- 所有冻结文件必须为仓库本地可用路径；外链图片不可作为运行时视觉依赖。
- 第三方、品牌和生成式资产必须记录来源、许可或用户授权。生成式资产另记录生成能力、日期和提示摘要。
- 图标须固定包名和版本，或引用本地 SVG；记录图标名、尺寸/`viewBox`、描边/填充、颜色、各状态和无障碍名称。
- 背景图、插画和纹理须记录原始尺寸、格式、压缩版本、显示区域、`cover`/`contain`、裁切焦点、遮罩/叠层、文字对比度及桌面/移动端变体。
- 探索期占位资产须明确标为候选；冻结与最终验收只能使用真实冻结资产。替代资产必须登记偏差，且须具名 UI 确认。
